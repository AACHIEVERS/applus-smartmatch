# ScholarSG — Singapore Scholarship Index

A static GitHub Pages MVP for indexing scholarships in Singapore.

## MVP
- Search scholarships
- Filter by education level
- Scholarship cards with eligibility, award, field and deadline
- Official-source links
- Responsive design
- No Vercel, no backend required

## Roadmap
1. Expand and verify the scholarship database
2. Add nationality / residency / academic-result filters
3. Add scholarship detail pages
4. Add deadline calendar and reminders
5. Add AI scholarship matching
6. Add admin data-management workflow

> Scholarship information can change. Always verify current eligibility, deadlines and terms on the official provider website.
